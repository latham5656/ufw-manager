```bash

```

> ```

После установки просто запустите:

```bash
sudo ufw
```

## 🔥 Что это такое?

**UFW Manager** — это красивый интерактивный скрипт для управления брандмауэром на Linux VPS.  
Вместо скучных команд — удобное **цветное меню** прямо в терминале.

Вызывается одной командой: `sudo ufw` — и вы уже в меню.

---

## ✨ Возможности

| Функция | Описание |
|--------|----------|
| 🟢 Включить / Отключить | Управление состоянием брандмауэра с подтверждением |
| 📊 Подробный статус | Расширенный вывод `ufw status verbose` |
| 📋 Список правил | Правила с цветной подсветкой ALLOW/DENY, поиском и IP-привязками (IPv6 скрыты) |
| ➕ Добавить правило | Порт с протоколом, IP-привязкой и описанием; валидация IP и порта до применения |
| 🚫 Блокировка IP | Быстрая блокировка/разблокировка IP с указанием причины и историей |
| ✏️ Редактировать правило | Изменить протокол, IP-источник и комментарий существующего правила без пересоздания вручную |
| 🗑️ Удалить правила | Удаление одного или нескольких правил по номерам через пробел/запятую |
| 📁 Профили | Сохранение и загрузка наборов правил — удобно для переключения конфигураций |
| 💾 Экспорт / Импорт | Экспорт правил в .sh скрипт для переноса на другой сервер |
| 📜 Лог брандмауэра | Просмотр `/var/log/ufw.log`: последние записи, только BLOCK, поиск по IP, живой режим |
| ⬆️ Обновления | Проверка раз в сутки; уведомление в шапке + пункт 14 для обновления прямо из меню |
| 🔄 Перезагрузка | Горячая перезагрузка правил |
| 💣 Сброс | Полный сброс до заводских настроек — требует ввода слова `СБРОС` |
| 🔁 Совместимость | `sudo ufw status`, `sudo ufw allow 22` — всё работает как раньше |

- 🐧 Linux (Ubuntu / Debian рекомендуется)

- `curl` для быстрой установки и проверки обновлений
- Bash 4+

## 🚀 Способы установки

### Способ 1 — одна команда (рекомендуется)

```bash
curl -fsSL https://raw.githubusercontent.com/latham5656/ufw-manager/refs/heads/master/install.sh | sudo bash
```

### Способ 2 — через git clone

```bash
git clone https://github.com/latham5656/ufw-manager.git
cd ufw-manager
sudo bash install.sh
```

Файлы устанавливаются в `/opt/ufw-manager/`, символическая ссылка создаётся в `/usr/local/bin/ufw`.  
Все стандартные команды `ufw` по-прежнему работают через встроенный проброс без изменений.

### Обновление

Повторный запуск установщика автоматически определяет версию и обновляет скрипт:

```bash
curl -fsSL https://raw.githubusercontent.com/latham5656/ufw-manager/refs/heads/master/install.sh | sudo bash
```

Также меню само сообщит о новой версии в шапке — проверка происходит раз в сутки в фоне.

## ➕ Добавление правила

При выборе пункта **5** скрипт валидирует порт и IP прямо в диалоге:

```
  Номер порта (или диапазон, напр. 8000:9000): 443

  Протокол:
    1) TCP
    2) UDP
    3) TCP + UDP (по умолчанию)
  Выбор [1-3]: 1

  Привязать к IP-адресу? (оставьте пустым — для всех): 192.168.1.10

  Описание (напр. 'Nginx HTTPS'): Nginx — HTTPS сервер

  ✅ Правило добавлено:
    Порт       : 443 (tcp)
    IP-привязка: 192.168.1.10
    Описание   : Nginx — HTTPS сервер
```

Если ввести некорректный порт или IP — скрипт сообщит об ошибке до вызова ufw.

## 🚫 Блокировка IP

Пункт **6** — быстрая блокировка нежелательных адресов с историей причин:

```
  Активные блокировки:
    🔴 45.33.32.156   — сканирование портов (2026-04-19 20:00)
    🔴 192.0.2.0/24   — спам (2026-04-18 14:30)

  1) Заблокировать IP
  2) Разблокировать IP
  0) Назад
```

Блокировка вставляется первым правилом (`ufw insert 1 deny`) — применяется немедленно.

## 📋 Список правил

Пункт **2** — поиск по порту, IP или описанию + цветная подсветка:

```
  Фильтр по порту/IP/описанию (Enter — все): 443

  [ 2] 443/tcp    ALLOW IN    Anywhere    # Nginx — HTTPS сервер
       🔒 только с IP: 192.168.1.10
```

- `ALLOW` — выделено зелёным, `DENY` — красным
- IPv6-дубли скрыты для чистоты вывода

---

## 📁 Профили правил

Пункт **9** — сохранение и восстановление полного набора правил:

- **Сохранить**: снимок текущих правил (`/etc/ufw/user.rules`) с именем и описанием
- **Загрузить**: заменить текущие правила из профиля (с подтверждением `ДА`)
- **Удалить**: убрать ненужный профиль

Профили хранятся в `/opt/ufw-manager/profiles/`.

---

## 💾 Экспорт / Импорт

Пункт **10** — перенос правил на другой сервер:

**Экспорт** создаёт `.sh` файл с `ufw allow/deny` командами:

```bash
# Перенос на другой сервер:
scp /opt/ufw-manager/exports/ufw-export-20260419-200000.sh user@server:/tmp/
ssh user@server sudo bash /tmp/ufw-export-20260419-200000.sh
```

**Импорт** применяет правила из указанного файла к текущей системе.

---

## 📜 Лог брандмауэра

Пункт **11** — просмотр `/var/log/ufw.log`:

| Режим | Описание |
|-------|----------|
| Последние 50 | Все последние события с цветовой подсветкой |
| Только BLOCK | Только заблокированные подключения |
| Поиск по IP | Все события для конкретного IP-адреса |
| Живой режим | `tail -f` с подсветкой, Ctrl+C для выхода |

> Если лога нет — включите: `sudo ufw logging on`

---

## 🗑️ Удаление правил

Пункт **7** — удалить сразу несколько правил:

```
  Номера правил через пробел или запятую (или 'q'): 3, 5 7

  ✅ Правило #7 удалено.
  ✅ Правило #5 удалено.
  ✅ Правило #3 удалено.

  Итого удалено: 3.
```

Удаление идёт с большего номера — индексы не сдвигаются.

---

## 🗑️ Удаление менеджера

**Из меню** (пункт 13) — введите слово `УДАЛИТЬ`. Правила UFW не трогает.

**Или вручную:**

```bash
sudo bash uninstall.sh
```
