## ⚡ Быстрая установка

```bash
curl -fsSL https://raw.githubusercontent.com/latham5656/ufw-manager/refs/heads/master/install.sh | sudo bash
```

> Или через `wget`:
> ```bash
> wget -qO- https://raw.githubusercontent.com/latham5656/ufw-manager/refs/heads/master/install.sh | sudo bash
> ```

После установки просто запустите:

```bash
sudo ufw
```

## 🔥 Что это такое?

**UFW Manager** — это красивый интерактивный скрипт для управления брандмауэром на Linux VPS.  
Вместо скучных команд — удобное **цветное меню** прямо в терминале.

Вызывается одной командой: `sudo ufw` — и вы уже в меню.

---

## ✨ Возможности

| Функция | Описание |
|--------|----------|
| 🟢 Включить / Отключить | Управление состоянием брандмауэра |
| 📋 Список правил | Показ всех правил с нативными комментариями и IP-привязками |
| ➕ Добавить порт | Правило с протоколом, IP и описанием (сохраняется как `# comment` в UFW) |
| 🗑️ Удалить правило | Удаление по номеру из меню |
| 🔒 Привязка к IP | Ограничение порта для конкретного IP-адреса |
| 💬 Нативные описания | Описание видно прямо в `ufw status numbered` после `#` |
| 🔄 Перезагрузка | Горячая перезагрузка правил |
| 💣 Сброс | Полный сброс до заводских настроек с подтверждением |
| 🗑️ Удаление менеджера | Удаление UFW Manager из системы прямо из меню |
| 🔁 Совместимость | `sudo ufw status`, `sudo ufw allow 22` — всё работает как раньше |

## ⚙️ Требования

- 🐧 Linux (Ubuntu / Debian рекомендуется)
- `ufw` установлен (`apt install ufw`)
- `curl` или `wget` для быстрой установки
- Bash 4+
- Права root / sudo

---

## 🚀 Способы установки

### Способ 1 — одна команда (рекомендуется)

```bash
curl -fsSL https://raw.githubusercontent.com/latham5656/ufw-manager/refs/heads/master/install.sh | sudo bash
```

### Способ 2 — через git clone

```bash
git clone https://github.com/latham5656/ufw-manager.git
cd ufw-manager
sudo bash install.sh
```

Файлы устанавливаются в `/opt/ufw-manager/`, символическая ссылка создаётся в `/usr/local/bin/ufw`.  
Все стандартные команды `ufw` по-прежнему работают через встроенный проброс без изменений.

---

## 🎮 Использование

### Открыть интерактивное меню:

```bash
sudo ufw
```

### Стандартные команды тоже работают (проброс в системный ufw):

```bash
sudo ufw status
sudo ufw allow 22/tcp
sudo ufw disable
sudo ufw reload
```

## ➕ Добавление порта — пошагово

При выборе пункта **5** скрипт задаст вопросы:

```
  Номер порта (или диапазон, напр. 8000:9000): 443

  Протокол:
    1) TCP
    2) UDP
    3) TCP + UDP (по умолчанию)
  Выбор [1-3]: 1

  Привязать к IP-адресу? (оставьте пустым — для всех): 192.168.1.10

  Описание (напр. 'Nginx HTTPS'): Nginx — HTTPS сервер

  ✅ Правило добавлено:
    Порт       : 443 (tcp)
    IP-привязка: 192.168.1.10
    Описание   : Nginx — HTTPS сервер
```

## 📋 Список правил с описаниями

Пункт **2** показывает все правила. Описания хранятся нативно в UFW и видны в любом инструменте:

```
  [ 1] 22/tcp                     ALLOW IN    Anywhere                   # SSH доступ
  [ 2] 443/tcp                    ALLOW IN    Anywhere                   # Nginx — HTTPS сервер
  [ 3] 8080/tcp                   ALLOW IN    Anywhere                   # Node.js API
       🔒 только с IP: 192.168.1.10
```

Описания сохраняются как нативные UFW-комментарии — видны в `sudo ufw status numbered` без менеджера.  
IP-привязки хранятся в `/opt/ufw-manager/descriptions.conf`.

## 🗑️ Удаление

**Из меню** (пункт 9) — удаляет скрипт и файлы, правила UFW не трогает.

**Или вручную:**

```bash
sudo bash uninstall.sh
```
